# Code Of Conduct

This project follows the Contributor Covenant Code of Conduct, version 2.1.

## Our Pledge

We pledge to make participation in this project a respectful, harassment-free
experience for everyone.

## Expected Behavior

- Be respectful and constructive.
- Assume good intent, but take responsibility for impact.
- Keep technical disagreement focused on the work.
- Accept feedback gracefully and help others do the same.

## Unacceptable Behavior

- Harassment, intimidation, or discriminatory language.
- Personal attacks or sustained disruption.
- Publishing private information without explicit permission.
- Any conduct that would reasonably make participation unsafe or hostile.

## Enforcement

Maintainers may remove comments, close issues, reject contributions, or restrict
participation when behavior violates this code. Security-sensitive or private
reports should use the process in `SECURITY.md`.
