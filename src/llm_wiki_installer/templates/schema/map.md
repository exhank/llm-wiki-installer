# Map Schema

Use this schema when creating a new `wiki/maps/*.md` page or substantially
reshaping an existing map.

## Frontmatter

```yaml
---
title: ""
tags:
  - map
created: YYYY-MM-DD
updated: YYYY-MM-DD
---
```

## Body

Recommended body:

```md
# Map Title

## Scope

## Core Pages

## Source Pages

## Open Questions

## Related Outputs
```
